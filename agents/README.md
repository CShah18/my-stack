# Agents

Declarative definitions of AI agents available in MyStack.

Each agent file (`<id>.agent.yaml`) follows the `AgentDefinition` schema validated by `@mystack/core`.

## Available Agents

| Agent ID | Name | Core Focus |
|---|---|---|
| `ceo` | CEO | Company strategy & vision alignment |
| `product-manager` | Product Manager | PRDs, feature specs & roadmap |
| `solution-architect` | Solution Architect | System design, ADRs & tech stack |
| `ui-designer` | UI/UX Designer | Design system, visual design & tokens |
| `frontend-engineer` | Frontend Engineer | React, Next.js, UI component development |
| `backend-engineer` | Backend Engineer | API design, node server logic & services |
| `database-engineer` | Database Engineer | Schema design, migrations & SQL queries |
| `ai-engineer` | AI Engineer | LLM prompt engineering, RAG & agent tools |
| `qa-engineer` | QA Engineer | Unit, integration & E2E testing |
| `security-engineer` | Security Engineer | Auth, RLS, vulnerability scanning & auditing |
| `performance-engineer` | Performance Engineer | Profiling, bundle optimization & metrics |
| `devops-engineer` | DevOps Engineer | CI/CD, containers & deployment |
| `documentation-engineer` | Documentation Engineer | Technical docs, API references & guides |
| `release-manager` | Release Manager | Versioning, changelogs & release coordination |
| `project-manager` | Project Manager | Task breakdown, timeline & dependency tracking |
