# Plugins

Plugins bundle agents, skills, workflows, rules, and templates into installable extension packages.

## Community & Ecosystem Plugins

- `react/` - React & Next.js development tools and rules
- `supabase/` - Supabase database, auth, and storage integrations
- `docker/` - Containerization workflows and deployment scripts
- `gcp/` - Google Cloud Platform infrastructure and deployment
- `aws/` - Amazon Web Services infrastructure and deployment
